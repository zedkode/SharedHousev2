# memoryagent

This folder stores concise, non-sensitive implementation memory for future agents and maintainers. It is not a substitute for source code, tests, architecture documents or issue tracking.

Required categories:

- `progress/` — completed task summaries and next work.
- `decisions/` — durable architecture/product decisions not already captured in an ADR system.
- `incidents/` — non-sensitive engineering lessons from incidents.

Never store credentials, private user/household data, production payloads, secret URLs, unreleased commercial terms or legal advice.
